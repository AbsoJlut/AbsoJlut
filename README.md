## 🚀 Мои проекты

### 🌐 [Kotya Lisichkina — сайт с административной панелью](https://kotyalisichkina.ru)

Один из моих основных проектов, который постоянно развиваю.

Начиналось всё с небольшого сайта, но постепенно он вырос в систему с собственной админкой, базой данных и множеством разных функций.

**Что реализовано:**
- Каталог фильмов, сериалов, аниме и игр.
- Административная панель для управления контентом.
- Система учёта заказов и статистика.
- Отзывы с модерацией и загрузкой фотографий.
- Галереи косплеев и открыток.
- Вишлист и другие интерактивные разделы.
- Поиск, фильтры и адаптивная вёрстка.

**Технологии:** PHP, JavaScript, HTML, CSS, MySQL, Linux, Nginx.

🔗 **[Посмотреть сайт](https://kotyalisichkina.ru)**

*Исходный код находится в приватном репозитории.*

### 🎡 Интерактивная система аукционов для Twitch

Система для проведения аукционов во время прямых трансляций.

Реализованы колесо с анимациями, обработка донатов, управление лотами, таймеры, рероллы, выкуп и интеграция с OBS.

Есть отдельная административная панель, через которую можно управлять аукционом прямо во время стрима.

**Технологии:** JavaScript, Node.js, PHP, MySQL, API, OBS, PM2.

*Проект находится в приватном репозитории.*
